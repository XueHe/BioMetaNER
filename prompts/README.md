# Abstract-Level NER Templates

The two light templates are snapshots of the existing direct and
candidate-grounded abstract-level prompt files, not newly tuned prompts.
They contain no abstracts, candidate lists, API keys or provider configuration.

Their inclusion does not establish which exact prompt/provider version produced
each historical result. In particular, the qualified LLM annotation CSV is not
silently reclassified as an independent run of these current templates.
Prompt hashes and preparation dates are recorded in provenance metadata.

No paid API experiment or prompt rerun is launched by this repository.
