- Use the minimal valid span.

- Precision matters, but do not omit clear repeated mentions or valid high-confidence MITC candidates.
- For infection phrases such as "E. coli infection", output the full phrase as DIS, not the microbe separately.

Output requirements:
- Output JSON only.
- Do not include markdown.
- Do not explain.
- Do not think step by step.
- Start with {"entities":[ and end with ]}.
- Do not output context, normalization, IDs, confidence, or reasons.
- Use compact one-line JSON when possible.
- Each entity object must contain only "type" and "text".
- Do not copy MITC metadata fields into the output.
